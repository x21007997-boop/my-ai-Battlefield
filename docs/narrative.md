# 回合纪事与小说卷宗

## 设计原则

小说不是脱离规则自由编造，而是确定性推演记录的叙事视图。每篇纪事都绑定一个历史分支节点，输入包括该回合的原始诏令、正式指标变化、触发事件、城市状态和上一章伏笔。

## 生成流程

1. 完成一回合正式结算；
2. 打开“推演档案”；
3. 点击“生成本回合纪事”；
4. DeepSeek 返回章节标题、场景摘要、后果、伏笔和完整正文；
5. 章节保存到当前历史节点；
6. 从旧节点重开时，新章节进入新分支，不影响原卷；
7. 点击“下载本分支小说卷宗”，沿当前节点向上汇编所有祖先章节。

## 叙事约束

- 不得改变正式指标和已经发生的事件；
- 未知信息只能作为传闻、怀疑或伏笔；
- 每章目标为 1000 至 1500 个中文字符；
- 少于 700 字符或缺失关键字段时自动重试一次；
- 使用晚明历史语境，但避免堆砌仿古词汇；
- 下一章可继承上一章伏笔，但不能读取兄弟分支的章节。

## 当前导出

当前支持两种格式：

- UTF-8 Markdown：便于继续编辑、版本管理或发布到内容平台；
- Word DOCX：包含历史风格封面、卷首说明、静态目录、章节分页、人物小传、决策年表、结局复盘、页眉和页码。

DOCX 采用 `narrative_proposal` 文档预设与 `editorial_cover` 封面结构，使用 Letter 纸张、1 英寸页边距、11pt 正文、1.333 倍行距，并以朱砂、墨绿和克制金色作为历史主题覆盖色。导出模块按需加载，不增加主页面的初始下载体积。
