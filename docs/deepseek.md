# DeepSeek 接入说明

## 使用方式

在“召集会议”弹窗中点击“请 DeepSeek 综合会商”。服务端会把当前指标、城市状态、最近决策、本月奏报和玩家拟议诏令发送给 DeepSeek。返回内容包括：

- 局势摘要；
- 三种幕僚立场；
- 每项建议的理由和风险；
- 一条可被确定性规则引擎识别的建议诏令；
- 当前信息缺口。

AI 不能直接修改世界状态。玩家采用建议后，仍须经过“分析影响”和“确认执行”，最终结果由本地规则引擎计算。

## 密钥安全

- 本地密钥保存于 `.env.local`；
- `.env.local` 已被 `.gitignore` 排除；
- 浏览器只访问 `/api/ai/council`，无法读取密钥；
- 服务端代理负责向 DeepSeek 添加鉴权信息；
- `.env.example` 只包含变量名称和占位内容；
- 如果密钥曾发送到聊天、截图或日志，建议在 DeepSeek 控制台轮换。

## 本地变量

```text
DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_MODEL=deepseek-v4-flash
```

修改变量后需要重新启动本地开发服务。

## 部署变量

部署环境必须配置以下服务端变量：

- `DEEPSEEK_API_KEY`：必需；
- `DEEPSEEK_MODEL`：可选，默认 `deepseek-v4-flash`。

不要把生产密钥写入 `.openai/hosting.json`、JavaScript 文件或任何可被浏览器下载的资源。

## 容错策略

- 强制请求 JSON 输出；
- 关闭思考模式以提升结构化结果稳定性；
- 空内容或非法 JSON 会自动重试一次；
- 上游错误只返回安全错误信息，不返回鉴权头；
- 所有正式指标仍以确定性规则引擎为准。
