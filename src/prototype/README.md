# 原型代码边界

本目录只存放原型和迁移期验证代码，不是正式游戏客户端目录。

## political

`political/` 是既有的弘光元年月度政治决策推演原型。它使用 `simulation.js` 的回合结算模型，服务于旧产品形态，不得作为实时战场引擎使用。

## battlefield

`battlefield/` 是正式战争模拟项目的浏览器验证入口。它只调用 `src/battlefield/` 的无头规则内核，用于快速检查正式项目的交互和数据契约；正式玩家客户端位于仓库根目录的 `godot/`。

## 规则边界

- 原型可以帮助验证功能，但不能创建第二套正式规则；
- 正式战场规则只能放在 `src/battlefield/`；
- 历史战役数据只能放在 `scenarios/`；
- Godot 只负责正式游戏的表现、输入和回放，不自行改写世界状态。
